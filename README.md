Задача: виконайти дослідницький аналіз набору даних, включаючи описову статистику та візуалізації.
Дані: використала IKEA dataset для EDA, статистичних тестів та машинного навчання.
Очистила дані: з 3694 записів залишилося 2962 унікальні товари.
Виявила, що найбільше товарів у Bookcases & shelving units, Chairs та Sofas & armchairs.
Ширина має найсильніший серед досліджених зв'язок із ціною — близько 0,72.
Перша гіпотеза показала статистично значущу різницю цін для товарів з іншими кольорами та без них.
Друга гіпотеза про вищу ціну Individual не підтвердилася: 545 проти 675 у IKEA.
Для прогнозування ціни протестувала Linear Regression, Random Forest та Gradient Boosting.
Найкращий результат у роботі показав Random Forest: R² ≈ 0,808, MAE ≈ 361, RMSE ≈ 602.
GridSearch не покращив тестовий результат, тому залишила базовий Random Forest.
